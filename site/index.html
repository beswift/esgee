// what it does

Capture is the easy part.
Finding it again is the point.

esgee is a tray app: global hotkeys, a drag-out shelf, and a local archive where every capture is indexed by its own pixels.

Drag-out shelf

Captures stack as floating cards in the corner. Drag one into Slack, an email, a ticket — it lands as a real file. Click to re-copy, or ignore it: it’s already saved. One key re-shoots your last region while you iterate on a UI.

Search what was on screen

Windows’ built-in OCR + SQLite FTS5 index every capture the moment it’s taken. Type a few words from any screenshot you’ve ever made:

connection refused
docker: connection refused on :5432…tue 09:14
curl: (7) Connection refusedjul 12

Record the region too

Same gesture, moving pictures: one hotkey records a region to MP4, and short clips get a paste-ready GIF automatically. Press again to stop.

REC 00:07
.mp4 + .gif

A memory for your agents

The archive is plain PNG/MP4 files plus a CLI. Point a coding agent at it and it can retrieve “that error dialog from last Tuesday” by content.

> esgee --search "token expired"
C:\Users\you\esgee\2026\07\14-31-08.png
> esgee --recent 5

// install

One line. Nothing leaves your machine.

Local-first by design: captures, OCR, and the search index all live in %USERPROFILE%\esgee. No account, no cloud, no telemetry.
